| `6.jpg`      | Centre-right photo          |
| `7.jpg`      | Bottom row — left           |
| `8.jpg`      | Bottom row — center-left    |
| `9.jpg`      | Bottom row — center         |
| `10.jpg`     | Bottom row — center-right   |
| `11.jpg`     | Bottom row — right          |
| `12.jpg`     | Bottom row — far right      |
